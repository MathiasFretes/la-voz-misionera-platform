## Contrato de extracción futura

1. Exportar colecciones/documentos V0 con una cuenta autorizada, en entorno controlado; no conectar la nueva Platform al Firestore antiguo.
2. Guardar original con procedencia y fecha, transformar a modelos nuevos tipados, reportar filas inválidas/duplicadas y revisar contenido sensible o derechos de imagen.
3. Cargar en PostgreSQL solo tras tener migraciones, permisos y revisión de datos. Mantener IDs V0 como referencia de migración, no como identidad de negocio pública.
4. Comprobar cardinalidad y muestras por entidad, enlaces multimedia, zonas horarias, consentimiento y diferencias entre documentos CMS y texto hardcodeado. Firestore V0 → exportación → transformación → PostgreSQL.
